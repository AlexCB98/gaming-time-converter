# Gaming Time Converter (Tkinter GUI)

A simple Python desktop application that converts hours into days through a graphical user interface built with Tkinter.

This project was built as a custom variation of the Miles to Kilometers converter from Angela Yu's Python course.

---

## Features

* Convert hours into days
* Simple and clean Tkinter interface
* User input through an Entry widget
* Dynamic result update using a Button
* Rounded results displayed with two decimal places

---

## What I practiced

* Tkinter GUI fundamentals
* Labels, Buttons and Entry widgets
* Grid layout management
* Functions and callbacks
* Reading user input with `.get()`
* Updating widget properties dynamically
* Numeric conversion with `float()`
* Rounding values with `round()`
